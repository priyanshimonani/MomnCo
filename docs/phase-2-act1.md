# Phase 2 — Gateway and Highlights

## Screen 1: Gateway
Use “Mom & Co. Annual Report (a very biased one),” “Audited with love,” a gently bobbing envelope, and an Open button. Loader: “Checking you are the best mom... verified.” Use the configured nickname.

## Screen 2: Highlights
Keep four count-up cards with icons and small SVG sparklines. Use short first-person labels for shared meals, Mom's problem-solving, “Did you eat?” check-ins, and borrowed patience. Add a draining patience gauge and a red Sleep row with a sad moon sticker.

Use pastel paper cards, washi accents, gentle tilt, and warm accessible text contrast.

## Acceptance
Count-ups, gauge, navigation, and reduced-motion behavior work; build passes.
